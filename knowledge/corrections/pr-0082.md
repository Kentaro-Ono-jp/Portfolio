# PR #82 implementation corrections

### Occurrence 1

- **PR:** PR #82
- **Mistake:** The noncanonical champion-report test relied on Windows newline translation, so its fixture became canonical on Linux and the expected rejection did not occur.
- **Correction:** Write a deliberately compact JSON byte representation so the noncanonical fixture is deterministic across operating systems.

### Occurrence 2

- **PR:** PR #82
- **Mistake:** The principal populated-schema verifier still expected migration revision 0004 after runtime lineage introduced revision 0005, so a successful upgrade to the real head was reported as failure.
- **Correction:** Align the verifier with revision 0005 and add a static regression test requiring every populated-schema verifier's declared head to equal Alembic's current head.
