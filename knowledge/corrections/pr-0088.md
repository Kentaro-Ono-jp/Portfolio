# PR 0088 implementation corrections

### Occurrence 1

- **PR:** PR #88
- **Mistake:** The GitHub Actions runtime reused fixed host ports from the Linux ephemeral range, allowing an unrelated outbound socket to block the API container bind on `127.0.0.1:58000`.
- **Correction:** The verification job now assigns aligned host ports and host-side service URLs below the Linux ephemeral range, the Web public URL follows its Compose override, and a regression test enforces that separation.

### Occurrence 2

- **PR:** PR #88
- **Mistake:** The identity boundary proof hard-coded the default Web public URL and rejected the valid CI-only published-port override before runtime verification could start.
- **Correction:** The proof now derives the expected loopback public URL from the resolved Compose port, the synthetic Dex client allows both local and CI callbacks, and unit tests cover aligned and invalid port mappings.
