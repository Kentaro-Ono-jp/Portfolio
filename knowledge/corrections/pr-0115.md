# PR #115 implementation corrections

### Occurrence 1

- **PR:** PR #115
- **Mistake:** Image publication retried CodeBuild without first reconciling immutable exact-source ECR tags left by an interruption after the build effect and before its remote checkpoint.
- **Correction:** Inspect all three exact tags before build, reuse only a complete valid digest set, reject partial sets, and compare fresh CodeBuild exports with ECR read-back before checkpointing.

### Occurrence 2

- **PR:** PR #115
- **Mistake:** Fallback registration could create a schedule and then lose its local checkpoint, leaving retry unable to adopt the existing same-name schedule.
- **Correction:** Persist the exact fallback intent before creation, attest the controller binding, and reconcile or adopt only an exact active schedule before recording the final checkpoint.

### Occurrence 3

- **PR:** PR #115
- **Mistake:** The exact-endpoint planner used copy and rename source identities both for conservative test selection and for the changed-file count, inflating the canonical inventory.
- **Correction:** Separate destination-focused change records from source-plus-destination selection identities and add copy and rename regression coverage.

### Occurrence 4

- **PR:** PR #115
- **Mistake:** The local classic-to-quorum RabbitMQ queue change had no bounded upgrade route for the project-scoped persistent broker volume.
- **Correction:** Add an explicit standalone verifier command that stops only this Compose project and removes only its synthetic RabbitMQ volume while preserving PostgreSQL, MinIO, and unrelated Docker resources.
