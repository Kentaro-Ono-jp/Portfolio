# Owner-authorized focus scratchpad

<!-- ips-role: reference -->
<!-- ips-rule: focus-scratchpad -->

## Read when

Read this reference only after the implementation agent decides to use
`.noel-focus/` for the current focused Issue. The decision is entirely the
agent's and requires no trigger, justification, or record.

## Delegation

The repository owner delegates full discretion over `.noel-focus/` to the
implementation agent. The agent may create, read, update, execute, reorganize,
retain, or delete any file or directory beneath it.

This rule imposes no required structure, template, size, retention period,
cleanup, reporting, reconciliation, or use/non-use record. Old focus material
may remain. The repository owner accepts responsibility for the directory's
contents, storage, retention, and eventual cleanup.

## Authority boundary

Scratchpad contents are local working material. Their existence alone does not
make them repository evidence, authority, accepted design, delivery state,
proof, or a source of truth. Any effect outside `.noel-focus/` remains governed
by the ordinary actor authority and lifecycle.

## Return

When scratchpad use is complete or no longer useful, return to the selected
route. No summary, deletion, or reconciliation is required.
