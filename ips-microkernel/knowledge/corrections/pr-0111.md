# PR #111 implementation corrections

<!-- ips-data: implementation-correction-occurrences -->

### Occurrence 1

- **PR:** PR #111
- **Mistake:** The environment root referenced an operator role whose identity policy and fixed permissions boundary did not effectively allow all AWS provider calls required to apply the declared resources.
- **Correction:** Replaced the unpublished Terraform IAM change with separately named Console-owned OperatorPermissions and OperatorBoundary definitions, accepted exact Console-owned role ARNs, and added a provider-version-pinned action matrix that verifies every planned operation against both policy layers.

### Occurrence 2

- **PR:** PR #111
- **Mistake:** The first live apply exposed provider-dependent tag authorization calls, an EC2 prefix-list read, and an API Gateway service-linked-role prerequisite that the initial static action matrix did not model.
- **Correction:** Added the exact tag and prefix-list actions to the Console-owned OperatorPermissions contract, recorded all four service-linked roles as owner-created prerequisites, and extended the two-layer action-matrix proof before retrying the saved environment configuration.

### Occurrence 3

- **PR:** PR #111
- **Mistake:** The second live apply proved that recovery from a partially created Security Group rule set requires `ec2:ModifySecurityGroupRules`, although a clean create-only plan does not exercise that action.
- **Correction:** Added the exact rule-modification action to OperatorPermissions and to both ingress and egress lifecycle rows in the two-layer action matrix before the final construction attempt.

### Occurrence 4

- **PR:** PR #111
- **Mistake:** The post-create real plan reached three provider refresh helpers that were absent from the pre-create matrix: Cognito client listing, MQ shared-resource description, and Secrets Manager resource-policy reading.
- **Correction:** Added only those three read actions to OperatorPermissions and their owning resource rows, and required a successful post-create plan before consuming the final construction attempt.

### Occurrence 5

- **PR:** PR #111
- **Mistake:** The MQ resource used accepted but non-canonical enum casing, so provider 6.58.0 read back `RabbitMQ`, `simple`, and `ebs` and produced a perpetual broker replacement after the first real refresh.
- **Correction:** Switched the MQ configuration and plan assertions to the provider's canonical read-back casing while preserving the RabbitMQ 4.2, EBS, and simple-authentication contract.

### Occurrence 6

- **PR:** PR #111
- **Mistake:** The third and final construction attempt exposed two delegated create dependencies absent from the matrix: API Gateway tags authorize through `apigateway:TagResource`, and Cloud Map private namespace creation invokes Route 53 hosted-zone creation under the caller.
- **Correction:** Added exact API Gateway tag rows, modeled the Route 53 write as a service-delegated action, added static create/delete ceiling coverage and destroy authority, and stopped further construction after the governed `3/3` attempt limit.
