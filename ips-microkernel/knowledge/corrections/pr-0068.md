# Implementation corrections for PR #68

<!-- ips-data: implementation-correction-occurrences -->

### Occurrence 1

- **PR:** PR #68
- **Mistake:** The new protected review and audit route tests did not explicitly prove that anonymous malformed document identifiers and review bodies fail authentication before CSRF or upstream validation.
- **Correction:** Exercise anonymous malformed review and audit requests at the route boundary and require canonical authentication failure with zero CSRF or upstream proxy calls.

### Occurrence 2

- **PR:** PR #68
- **Mistake:** The Web review proxy combined malformed `If-Match`, `Idempotency-Key`, and body values in one negative test, so parameter parity was not isolated on an otherwise-valid request.
- **Correction:** Exercise malformed `If-Match` and malformed `Idempotency-Key` independently with a valid peer header and valid review body, requiring canonical validation failure and zero upstream calls.

### Occurrence 3

- **PR:** PR #68
- **Mistake:** The Web runtime review parser lacked a complete reachable-variant and inverse-negative matrix for the relational review response union.
- **Correction:** Exercise every reachable unreviewed, approved, and corrected classification variant through the Web proxy and reject one impossible relationship for each discriminator.

### Occurrence 4

- **PR:** PR #68
- **Mistake:** The failure-artifact upload gate enumerated credential patterns but did not cover submitted source text, submitted private data, or private profile claims retained by browser artifact containers.
- **Correction:** Keep Playwright trace, video, screenshot, and HTML containers outside the public artifact root; register exact private-content canaries before browser navigation; redact raw and encoded canary forms from public files and ZIP members; and fail the upload gate if a private browser container remains public.

### Occurrence 5

- **PR:** PR #68
- **Mistake:** The browser proof registered only the expected reviewer principal before later identity and audit assertions, so an unexpected received reviewer or actor identifier could enter public JUnit before it became a private-profile canary.
- **Correction:** Register every observed reviewer and audit actor value synchronously before correlation, shape, identity, or ordering assertions can serialize a failure, and cover an expected-versus-unexpected JUnit mismatch with the public artifact sanitizer.

### Occurrence 6

- **PR:** PR #68
- **Mistake:** The percent-encoded canary variant used the encoder's default safe slash and the regression proof reused only a partial variant matrix, allowing strict `%2F` submitted PDF content to survive in ordinary files and ZIP members.
- **Correction:** Generate strict no-safe-character and lowercase-hex percent variants, and prove raw, base64, URL-safe padded and unpadded, strict percent, and lowercase percent forms with an independent encoder in both ordinary and ZIP artifact payloads.

### Occurrence 7

- **PR:** PR #68
- **Mistake:** The Web audit chronology validator compared accepted RFC 3339 timestamp strings lexically, so variable fractional precision and offsets could make real-time ascending history fail while real-time descending history passed.
- **Correction:** Normalize each timestamp to an offset-adjusted UTC whole second plus its precision-preserved fractional digits, compare that instant first, and use the canonical event identifier only as the equal-instant tie-break; prove ascending, descending, and tied offset/fraction cases at contract, upstream proxy, and browser client boundaries.
